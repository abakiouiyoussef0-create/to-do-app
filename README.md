# To-Do List App

A simple full-stack to-do list application with a clean, responsive UI.

## Features

- Add new tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Persistent storage (tasks are saved even after refreshing or restarting)
- Responsive design — works on desktop and mobile
- Smooth animations when adding tasks

## Tech Stack

**Frontend:**
- HTML5
- CSS3 (Flexbox, media queries, animations)
- Vanilla JavaScript (fetch API for backend communication)

**Backend:**
- Python
- Flask (web framework)
- Flask-CORS (cross-origin requests between frontend and backend)
- SQLite (lightweight file-based database)
